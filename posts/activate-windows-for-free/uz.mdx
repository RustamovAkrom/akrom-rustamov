# Windows’ni amaldagi litsenziya bilan faollashtirish

Windows’ni faollashtirish uchun rasmiy vositalar va o‘zingizga tegishli litsenziyadan foydalaning.

## Faollashtirish holatini tekshiring

1. **Sozlamalar → Tizim → Faollashtirish** bo‘limini oching.
2. Faollashtirish holati va Windows ko‘rsatgan xabarni tekshiring.
3. Mahsulot kalitingiz bo‘lsa, **Mahsulot kalitini o‘zgartirish**ni tanlab, uni kiriting.

## Muammolarni bartaraf etish

Windows avval faollashtirilgan bo‘lsa, **Sozlamalar → Tizim → Faollashtirish → Muammolarni bartaraf etish** bo‘limini oching. Raqamli litsenziyangizga bog‘langan Microsoft hisobiga kiring va ko‘rsatmalarga amal qiling.

Uskuna almashtirilganda faollashtirish holati o‘zgarishi mumkin. Muammo bartaraf etilmasa, [Microsoft yordam xizmatiga](https://support.microsoft.com/windows/activation-in-windows) yoki litsenziyani sotgan do‘konga murojaat qiling.

Norasmiy faollashtirish skriptlari va internetdan kod yuklab darhol ishga tushiradigan buyruqlardan saqlaning: ular qurilmangizga zarar yetkazishi va haqiqiy Windows litsenziyasini bermasligi mumkin.
