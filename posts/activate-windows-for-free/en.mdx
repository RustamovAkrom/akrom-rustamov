# Activate Windows with a valid license

Use the official activation tools to connect Windows to a license you own.

## Check activation status

1. Open **Settings → System → Activation**.
2. Review the activation status and any message shown.
3. If you have a product key, choose **Change product key** and enter it.

## Troubleshoot activation

If Windows was activated before but no longer is, open **Settings → System → Activation → Troubleshoot**. Sign in to the Microsoft account linked to your digital license and follow the prompts.

A hardware change can affect activation. If the troubleshooter cannot restore it, use [Microsoft Support](https://support.microsoft.com/windows/activation-in-windows) or the retailer that provided your license.

Avoid unofficial activation scripts and commands that download and run code. They can compromise your device and do not provide a legitimate Windows license.
