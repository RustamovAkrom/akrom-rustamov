# Claude Code со сторонним API-провайдером

В этой инструкции показано, как подключить Claude Code к внешнему API-провайдеру. Доступность, стоимость и условия зависят от провайдера и могут меняться. Это не официальный бесплатный тариф Anthropic.

## Установите Claude Code

Откройте терминал и выполните актуальные инструкции из [официальной документации Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview).

## Создайте ключ API у провайдера

Зарегистрируйтесь у провайдера, поддерживающего формат API Claude Code, и создайте ключ в его панели управления. Перед отправкой данных проверьте стоимость и правила конфиденциальности.

## Настройте адрес API

Задайте ключ и адрес API по инструкции провайдера. Для временной сессии терминала можно использовать переменные окружения:

```sh
export ANTHROPIC_API_KEY="ключ-провайдера"
export ANTHROPIC_BASE_URL="https://provider.example/api"
claude
```

Используйте точный адрес, который выдал провайдер. Не добавляйте API-ключи в репозиторий и не публикуйте их на скриншотах. Если ключ стал общедоступным, сразу отзовите его.
